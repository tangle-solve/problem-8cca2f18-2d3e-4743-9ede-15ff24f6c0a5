### ALGO-000162: Strongly polynomial linear programming
- **Subfield:** Linear optimization and enumeration
- **Open:** Solve general rational linear programs using a number of arithmetic operations polynomial only in the numbers of variables and constraints, while controlling intermediate bit lengths.
- **Status:** Open since polynomial-time LP algorithms appeared. Ellipsoid and interior-point methods are polynomial in encoding length; Tardos’s strongly polynomial results apply to important restricted coefficient structures.
- **Type:** theory
- **Why:** Would make LP complexity independent of numerical scaling in the strongest standard sense.
- **Key works:** Khachiyan (1979); Karmarkar (1984); Tardos (1986), *A Strongly Polynomial Algorithm to Solve Combinatorial Linear Programs*.
- **Related:** Numerical optimization—conditioning-independent complexity.
